# Marvel Samuel — Portfolio

Personal portfolio website for Marvel Samuel, Business & Technology Strategist (Customer Success, Product, AI Solutions, Digital Transformation).

A single static page (`index.html`), no build step needed.

**Features:** light/dark theme toggle, animated impact numbers, interactive career timeline, filterable work and capabilities grid, contact section with copy-to-clipboard email.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

Tip: name the repository `<your-username>.github.io` to have the site served at `https://<your-username>.github.io/`.
